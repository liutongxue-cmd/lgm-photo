# 流光小记（lumiere.cn）· 摄影手记网站 —— 部署与维护教程

纯前端静态网站，托管永久免费（GitHub Pages）。代码已内置自动构建脚本，
你要做的只有两件事：**一次性部署**（约15分钟）和**日常往文件夹里丢照片**。

---

## 一次性部署（共5步）

### 1. 注册 GitHub 账号
打开 https://github.com 注册（国内邮箱即可，不需要翻墙；访问慢可装免费加速器 Watt Toolkit）。
用户名建议用拼音，如 `liuguangming`。

### 2. 创建仓库并上传代码
1. 右上角「+」→「New repository」，名称填 `lumiere`（或其他喜欢的名字），保持 **Public**，创建；
2. 仓库页点「Add file」→「Upload files」，把本项目**全部文件和文件夹**拖进去；
   ⚠️ 注意包含隐藏文件夹 `.github`（Windows 需在资源管理器勾选"查看→隐藏的项目"才能看到，漏了它网站不会自动构建）；
3. 点「Commit changes」提交。

### 3. 开启 Pages（注意选 Source）
1. 仓库「Settings」→ 左侧「Pages」；
2. **Source 选择「GitHub Actions」**（不是 Deploy from Branch）；
3. 等 2~3 分钟，仓库顶部「Actions」标签里出现绿色√后，访问：
   `https://你的用户名.github.io/lumiere/`

### 4. 填写配置（让网站读取你的照片）
编辑 `src/config.ts`（点文件 → 铅笔图标）：

```ts
github: {
  user: "你的GitHub用户名",
  repo: "lumiere",
  branch: "main",
},
```

提交保存，会自动触发重新构建，2分钟后生效。
（留空时网站显示演示占位图；填写后自动切换为你上传的真实照片。）

### 5. 绑定域名 lumiere.cn（可选）
在域名 DNS 解析处（腾讯云控制台 → 域名注册 → 我的域名 → 解析）添加 5 条记录：

| 记录类型 | 主机记录 | 记录值 |
|---------|---------|--------|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | 你的用户名.github.io |

然后到 GitHub 仓库 Settings → Pages →「Custom domain」填 `lumiere.cn`，
保存，等几分钟后勾选「Enforce HTTPS」。
（服务器在境外，不需要ICP备案。）

## 日常维护：传图即更新（每次1分钟）

1. 打开仓库，进入 `photos/` 下对应分类文件夹：
   - `street` → 扫街　`portrait` → 人像　`landscape` → 风景　`life` → 生活记录
2. 「Add file」→「Upload files」拖入照片，提交；
3. **完成。** 网站运行时自动读取文件夹，刷新即见（视频放 `.mp4` 同样支持）。

**小贴士：**
- 单张建议 2MB 以内（SnapBridge 手机图刚好；太大可用微信发一遍再保存自动压缩）；
- 文件名建议日期开头：`2026-08-青岩-01.jpg`，新作品自动排最前；
- 点开放大后，EXIF（光圈/快门/ISO/镜头）会从照片里**自动读取**；
- 改"关于我"文字、联系方式：编辑 `src/config.ts` 里的 `about` 部分。

## 网站特性一览

- 首页沉浸式照片轮播（缓慢淡入 + 轻微推移）＋下滑可见的分类卡片
- 四大板块：扫街（瀑布流+组图故事集）/ 人像（画廊滑块+系列分组+视频悬停预览）/ 风景（沉浸视差+网格双视图+宽幅全景）/ 生活记录（手账时间轴+文字备注）
- 全屏查看器：点击位置光晕扩散开启、滚轮/双指缩放、EXIF侧栏、视频自定义控件
- 桌面端光标聚光（暗房手电效果）；手机端单点出光晕、滑动拖出流光轨迹
- 缩略图悬停扫光、滚动光影显现、章节暗化转场、导航自动隐藏
- 全端响应式，移动端自动降级复杂光效
